## Supabase hardening
Run `supabase/vendor_mess_cards_hardening.sql` in Supabase SQL Editor to enforce:
- one menu per vendor per day
- non-empty menu items
Live Demo

https://full-stack-dev-project.vercel.app/welcome.html

Features

- View daily and weekly mess menus

- Submit feedback about food quality

- Report complaints or suggestions

- Vendor interface to update menu information

- Simple and user-friendly web interface

Technologies Used

-- Frontend: HTML, CSS, JavaScript

-- Backend / Database: MySQL

-- Deployment: Vercel

Project Purpose

Many college mess systems rely on manual communication or messaging groups, which often leads to confusion and lack of transparency. Mess-Buddy aims to provide a structured digital solution that improves communication between students and mess management.
